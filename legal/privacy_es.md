# Política de privacidad y protección de datos
## 1. Medición de audiencia (Plausible Analytics)
Este sitio utiliza la herramienta de medición de audiencia Plausible Analytics (autohospedada). Esta herramienta está configurada con un estricto respeto a la privacidad:

- No utiliza ninguna cookie.

- No recopila ningún dato personal o identificativo.

- No permite rastrear a los usuarios de un sitio web a otro.

- Los datos estadísticos de tráfico se anonimizan y agregan por completo desde el momento de su recogida.

## 2. Almacenamiento local (Local Storage)
El sitio puede almacenar de forma temporal o persistente datos técnicos no personales en el almacenamiento local (localStorage) de tu navegador. Estos datos se utilizan exclusivamente para garantizar el correcto funcionamiento técnico del sitio (por ejemplo, para guardar tus preferencias de juego).

## 3. Servicios de terceros, CDN y API externas
Para garantizar su visualización y correcto funcionamiento técnico, el sitio recurre a recursos externos (como redes de entrega de contenido - CDN, fuentes web como Google Fonts, mapas base de CartoDB, librerías de mapas como MapLibre y API como countries.dev o Wikipedia).
Cuando tu navegador carga estos recursos, estos servicios de terceros pueden recibir técnicamente datos técnicos básicos (como tu dirección IP), de acuerdo con sus propias políticas de privacidad. Ningún dato personal es cedido, vendido o transmitido a terceros por el editor del sitio.

## 4. Ausencia de recogida de datos personales
Dado que el sitio no realiza registros de usuarios, no recopila direcciones de correo electrónico y no utiliza rastreadores publicitarios, no se registra ningún dato personal individual. En consecuencia, no existe ningún perfil de usuario que deba ser consultado, modificado o eliminado.
